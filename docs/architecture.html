Build Pipeline · Architecture

zig-metallib

Zig shader source becomes an Apple .metallib through four Zig tools — rewrite, assemble, describe, pack — with no Metal Shading Language, no xcrun metal, and no C/Objective-C in the build. Apple's runtime does only the final AIR → GPU step.

The core

Four Zig tools

  • air_splice — rewrite IR to AIR
  • assembler — IR text → bitcode via std.zig.llvm.Builder
  • metadata — Zig types → !air.*
  • metallib — MTLB container packer

Verified

Runs, not just compiles

  • zig build test — 90 tests
  • zig build check — 42 ok, 0 fail
  • pixel-exact renders + every dispatch
  • Apple's assembler accepts the printed IR too

Not in the build

No Apple toolchain

  • no .metal / MSL
  • no xcrun metal
  • no checked-in .ll
  • no C / Objective-C
